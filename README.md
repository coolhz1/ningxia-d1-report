# 宁夏日前电价 D+1 回测报告

数据范围：2026-10-01 至 2026-11-05。静态阅读站点，包含按月指标、36天逐日电价对比、气象与市场边界量图。

## GitHub Pages 发布

1. 将本目录内容推送到独立的 `ningxia-d1-report` 仓库的 `main` 分支。
2. 进入仓库 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**，Branch 选择 **main**，Folder 选择 **/(root)**，保存。
4. 发布成功后的地址为 `https://<GitHub用户名>.github.io/ningxia-d1-report/`。

`.nojekyll` 使站点按现有静态文件直接发布，所有资源路径均为相对路径，支持项目子路径部署。

## 本地预览

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

用浏览器打开 `http://127.0.0.1:8766/`。浏览器读取 `report.json`，不需要安装网页构建依赖。
