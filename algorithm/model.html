任务定义与输入契约

令T为交割日，D=T−1为发布日。小时模型使用内部小时h=0…23，展示时段s=h+1。夜间为时段1至8，日间为9至17，晚间为18至24。标签为各时段实际日前价格，单位元/MWh。

输入对象维数索引与用途
hourly44列连续小时索引，供两个森林训练与预测
night34列交割日索引，低价分类使用34列，条件分位数使用6列
context5列日级历史价格锚点，供夜间价格校准
evening2列晚间竞价空间与风电预测均值
night_oof / evening_oof历史预测与标签记录预测日、原始水平、实际中位数、训练截止日

所有学习与校准使用日期早于T的数据。目标日的全天市场预测曲线可以用于当日统计，价格历史只从T−1及更早的日前价格构造。T日及未来实际价格由回测评分环节读取。

44维小时特征与构造

特征由日历5列、原天气7列、市场及曲线形状24列、滞后价格8列组成。表中日均值、日极值和秩均在同一目标日的预测曲线上计算。m_space_future_ramp1在日末取0，ramp1/ramp3向前取连续历史曲线。

net_demand = load + tie − nonmarket
space = net_demand − renewable_total_forecast
ratio_renew = renewable_total_forecast / max(load, 1)
space_relative = (space − day_min) / (day_max − day_min + 1)

派生空间与新能源占比还需要新能源总出力预测。该原始列参与构造，44列输入中的m_pv和m_wind各自保留。日历day_type取工作日0、普通周末1、节假日2，法定调休由日历库处理。

短窗森林训练后保存每个训练样本在每棵树的叶节点。对一个查询小时，收集同叶的历史价格，每棵树的同叶样本总权重归一为1。把240棵树的样本权重合并，取累计权重达到50%的首个价格，得到Q50,S。同一森林另用标准predict得到均值μS。

wᵢ(x) = (1/M) Σₘ 1[leafₘ(xᵢ)=leafₘ(x)] / Nₘ(x)
Q50,S(x) = 首个累计权重≥0.5的历史价格
Q̃50,S = 40, 若Q50,S<60；否则为Q50,S
B(h) = 0.8 Q̃50,S(h) + 0.2 μL(h)
R(h) = 0.8 μS(h) + 0.2 μL(h)

B为基础小时价格，R为曲线形状与并列排序分数。中位数更贴合绝对误差目标，均值提供连续的日内形状。每次训练分别验证60与180天完整小时数、特征和标签有限性。

夜间低价事件与条件价格分布

夜间标签YN(T)取时段1至8的实际价格中位数。先判断该日夜间中位数是否≤60，再在YN>60的历史日上学习条件价格分位数，分别处理低价事件和正常价格水平。

子模型实现参数
低价概率p34维 → RobustScaler → LogisticRegression窗口最多240天，L2，C=1，lbfgs，max_iter=2000
条件分位数6维 → RobustScaler → 6个QuantileRegressorα正则=0.001，价格除400，solver=highs
分位数网格0.05、0.10、0.20、0.30、0.40、0.50训练标签仅用夜间中位数>60的日期

两个缩放器分别在本次历史窗口的分类与价格特征上拟合。若低价标签只有一种类别，概率使用平滑常数(低价日数+1)/(历史日数+2)。至少需要30个历史日及9个正常价格日，否则报错。

若 p≥0.5，原始夜间水平 Lraw=40
若 p<0.5，α*=(0.5−p)/(1−p)
各条件分位数预测先做累计最大值，消除分位数交叉
Lraw = 在[0.05,…,0.50]网格上插值 Qpositive(α*)
网格外取最近端点，Lraw裁剪到[40,1000]

α*来自“低价状态概率p+正常价格条件分布”的混合中位数。p越接近0.5，选择的正常价格分位点越低。低价状态采用40元/MWh水平，再由历史校准调整。该结构明确区分低价概率与非低价时的价格幅度。

历史OOF与固定节点单调校准

OOF在这里指逐日向前滚动产生的历史预测。每个历史日s的预测仅由s之前的训练数据生成，记录train_end<s。夜间校准取T前90个完整日，晚间校准取T前180个完整日。

基础价格映射在9个固定价格节点上分段线性插值。节点依次为40、80、140、220、300、380、500、700、1000。优化目标是历史日级价格误差的L1损失，叠加对恒等映射和上下文系数的L1先验。

ŷs / 400 = A(Lraw,s) β + g(Lraw,s) · z̃s γ
g(L) = clip((L−60)/60, 0, 1)
min mean(|Ys/400 − ŷs/400|)
    + (0.02/9) Σk |βk − knotk/400| + 0.005 Σj |γj|
约束 β1≤…≤β9，0.1≤βk≤2.5

A为相邻固定节点的线性插值权重。单调约束施加于9个基础节点，夜间再叠加门控的价格上下文，最终水平裁剪到40至1000。优化通过scipy.optimize.linprog(method='highs')求解。晚间映射使用相同节点与恒等先验，上下文维数为0。

夜间上下文定义
known_high1前一日全日价格>60部分的中位数，无有效值时向前填充，再兜底100
known_high7先滞后一天，再取近7日上述日级中位数的中位数，min_periods=1
known_evening_high1前一日晚间价格>60部分的中位数，缺失时用known_high1
known_night_1前一日夜间8小时价格中位数
known_evening前一日晚间7小时价格中位数

上下文只用本次校准历史窗口拟合RobustScaler，使用同一变换处理T日。历史OOF会随每日新增样本更新，模型验证其训练截止日早于各预测日。

晚间供需水平与24小时融合

晚间标签是时段18至24实际价格的中位数。输入为相同7小时的竞价空间与风电预测均值，在T之前最多240天上拟合RobustScaler和中位数QuantileRegressor，quantile=0.5、alpha=0、价格除400，至少需要3个历史日。原始水平裁剪到40至1000，再经180天历史OOF固定节点映射得到LE。

LN = 夜间90天校准后的价格水平
LE = 晚间180天校准后的价格水平
夜间时段1…8   raw(h) = LN + R(h) − median(R(夜间))
日间时段9…17  raw(h) = B(h)
晚间时段18…24 raw(h) = 0.75 B(h) + 0.25 LE
最终价格 pred(h) = 40, 若raw(h)<60；否则为raw(h)
并列排序分数 rank_score(h) = R(h)

夜间叠加去中位数后的均值曲线，保持价格水平与日内形状的分工。晚间25%的日级水平减少小时曲线的系统偏移。40至1000的裁剪作用于夜间及晚间水平估计，最终小时融合后执行低价映射，原始小时曲线保留其数值范围。

最终低价映射会产生多个40元/MWh并列小时。峰谷选择先按最终价格排序，再按R排序，最后按时段先后排序。排序分数与最终价格分别保存。

接口、输出及失败条件

# 由准备好的DataFrame与历史OOF训练目标日快照
prediction, snapshot = train_predict(
    target, bundle, night_oof, evening_oof
)

# 使用该目标日快照和目标特征再次推理
prediction = snapshot.predict(
    bundle['hourly'], bundle['night'],
    bundle['context'], bundle['evening']
)

核心入口位于slim_d1_model.py，fit_snapshot返回包含森林、叶样本、夜间模型、晚间模型及两套校准参数的快照。输出列为date, period, raw, pred, rank_score, night_level, night_low_probability, evening_level, model_version，回测环节再附actual。

目标日应恰好24小时并按0至23时有序排列。60/180天森林历史不足、90/180天OOF校准日期不全、输入非有限值、夜间有效日不足、OOF训练截止异常或线性规划失败时，当前实现抛出异常。每个快照绑定一个目标日，后续交割日需要相应输入和重新拟合。

数据适配层slim_d1_pipeline.py使用现有冻结特征缓存，核心模型本身接收DataFrame。快照记录两个森林、两个日级模型、两个校准器的训练截止，以及实测出力可用截止。
